# mesh-convex-hull

给物理体自动生成凸包后，面朝内、体积还算小了六倍：重复顶点只差 1e-7 却没有被合并，初始四点共面时直接崩溃，贴在面上的点被漏掉，扩展后壳里还留着可见面，法线指向内部，体积与解析值差六倍，三面共边却仍被导出，壳外点也能通过校验，批量处理时前后点集的面表互相串，eps 传 0 还会除零。hull/build.py 是核心，tests/test_build.py 15个红。要修的是：去重不按 eps，浮点重复点导致退化；初始四面体不检查体积，退化后崩溃；可见判定用 `>` 而不是 `>=`，共面点漏判；扩展时不删可见面，出现内部面；面绕序不统一，法线朝内；体积不除 6，数值差 6 倍；非流形不检测，导出失败；点不在壳内不校验，结果错误；批量共用面表，点集之间串；eps<=0 不校验，除零。

## 运行方式

```text
python -m pytest tests -q
```

初始输出应恰好包含 `15 failed`（没有 collection、import 或 syntax error）；15 条测试全部因 `NotImplementedError` 失败。实现 `hull/build.py` 后应全部通过。
